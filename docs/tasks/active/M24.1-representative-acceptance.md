## 1. Goal

Prove the deterministic golden demo seed and run one full representative acceptance pass over the seeded dataset: baseline gates green, health/auth/tenant-safety checks pass, a bus group-tour golden scenario is walked in a real browser without major errors, and the admin client bundle contains no secrets. This is the first slice of M24; it does not attempt all three golden scenarios.

## 2. Current problem

M00–M16 features have shipped through PR #72/#73, but no recorded end-to-end acceptance run exists against the deterministic seed. The seed script (`nmt-analytics-api/src/scripts/seed_demo.ts`, seed id `travline_golden_demo_2027`) exists and is safe-by-design (explicit `DEMO_TARGET_ORG_ID`, `DEMO_RESET_CONFIRMATION` gate, `seed_owned_records` ownership tracking) but has not been verified end to end in a recorded pass.

## 3. Required discovery before editing

Completed in this run (2026-10-10):

- Seed audited: 5 packages (antalya/istanbul/dubai = flight; budva/mostar = bus), deterministic ids, groups, accommodation requirements, payments, `seed_owned_records` registration. Target org resolution refuses unknown/implicit orgs.
- `/api/health` exists (`src/routes/health.ts`) and is covered by `src/scripts/smoke.ts`.
- Test baselines: 68 API vitest files, 42 admin test files. No Playwright infra — browser acceptance uses agent-browser manual walkthrough.
- API `.env` present with Supabase service creds, `SEED_USER_ID` (confirmed auth user), `DEV_BYPASS_AUTH=true`, `DEV_ORG_ID` currently pointing at the real NMT Analytics org (d9c9c298…) — the acceptance run must override to the demo org.
- Supabase org inventory checked: target org is `Demo Travel Agency` (id `de0feae6-ec1d-4122-8347-d76dc31a00b8`), currently has 0 `seed_owned_records`. NMT Analytics org must not be touched.

## 4. In scope

1. Run the golden seed against `Demo Travel Agency` and verify output (record counts, org linkage, deterministic ids).
2. Baseline gates: API `npm ci && npm run build && npm test`; admin `npm ci && npm run lint && npm test && npm run build`.
3. Local runtime acceptance with `DEV_ORG_ID` overridden to the demo org:
   - `/api/health` healthy without auth;
   - real-token auth smoke (`/api/me` with a minted Supabase session);
   - tenant scoping spot-check: seeded list endpoints return only demo-org data, no NMT Analytics ids.
4. Browser walkthrough (agent-browser) of golden scenario 1, bus variant: packages list → Budva Summer departure → passengers/group → payments → seating → rooming → documents; capture console errors.
5. Secrets scan of the built admin bundle (`dist/`) for service-role keys, JWT secrets, anon keys misplacements.
6. Record evidence in `docs/tasks/evidence/` and report per the completion contract.
